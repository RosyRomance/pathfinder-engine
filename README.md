# Pathfinder

A modular, graph-based engine for discovering and optimizing DeFi opportunities.

## What is Pathfinder?
Pathfinder models DeFi protocols and capital flows as a graph, enabling
systematic analysis of yield, risk, liquidity, and exit constraints.

## Demo: LST Staking Optimization
This hackathon demo focuses on optimizing ETH staking across LSTs
(stETH, rETH, cbETH), balancing yield and exit risk.

## Architecture
(Pathfinder Engine)
- Graph Model
- Analyzer
- Optimizer
- Executor

## Why it matters
Most staking tools focus on APY.
Pathfinder treats exit risk and liquidity as first-class constraints.
